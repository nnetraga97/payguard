# ML/AI Learning Scaffold Plan

## Intent

Refocus PayGuard so the ML/AI implementation is done by the user, with Codex acting as a staff-level mentor and reviewer.

## Constraints

- No cloud spend.
- No model, feature engineering, training, scoring, RAG, or fine-tuning implementation by Codex.
- Keep the repo public and company-neutral.
- Keep payments context in every ML/AI milestone.

## Steps

1. Add mentor guardrails and ML/AI ownership notes.
2. Add local-only Python environment and docker support.
3. Add docs for Phase 1 classical fraud scoring and later ML/AI tracks.
4. Add service contracts for fraud scoring and dispute assistant without implementations.
5. Update progress and budget documents.
6. Verify shell syntax, Maven tests, and git hygiene.
