# Phase 0 OCI Scaffold

## Intent

Create reviewable Phase 0 infrastructure scaffolding without provisioning cloud resources.

## Steps

1. Re-read `AGENTS.md`, `PROGRESS.md`, and `BUDGET.md`.
2. Create a branch for scaffold work.
3. Add OCI provision and teardown scripts with hard budget guardrails.
4. Add notes for the first payments and infrastructure concepts.
5. Run dry-run verification only.

## Non-Goals

- Do not create OCI resources in this step.
- Do not scaffold Java/Spring code until the infrastructure plan is reviewed.
- Do not activate or touch Azure.
